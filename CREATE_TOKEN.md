# 🔑 Создай GitHub Personal Access Token

Чтобы я мог автоматически создать репозиторий на GitHub, нужен Personal Access Token.

---

## 1️⃣ Перейди на GitHub Settings

https://github.com/settings/tokens/new

Или:
1. GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Нажми "Generate new token (classic)"

---

## 2️⃣ Настройки токена

- **Note:** `Railway Bike Scraper Deployment`
- **Expiration:** 90 days (или больше)
- **Scopes:** Выбери:
  - ✅ `repo` (Full control of private repositories)
  - ✅ `admin:repo_hook` (Full control of repository hooks)
  - ✅ `user` (Read user profile data)

---

## 3️⃣ Сгенерируй токен

Нажми "Generate token" и скопируй появившийся токен.

**⚠️ ВАЖНО:** Токен показывается только один раз! Скопируй его сейчас!

---

## 4️⃣ Используй токен

После того как скопируешь токен, напиши мне, и я создам репо на GitHub и закачаю код.

Просто скажи: "Готово, вот токен: ghp_..."

---

## ✅ Готово!

После получения токена я:
1. Создам репозиторий `bike-scraper` на GitHub
2. Запушу весь код
3. Настрою Railway для автоматического deployment

Это займет 2 минуты! 🚀
