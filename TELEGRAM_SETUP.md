# 🤖 Telegram Бот - Настройка на Railway

Пошаговая инструкция для включения Telegram бота на Railway.

## 1️⃣ Создать Telegram бота

### Шаг 1: Открыть BotFather

В Telegram найдите `@BotFather` и откройте чат.

### Шаг 2: Создать нового бота

Отправьте команду:
```
/newbot
```

### Шаг 3: Следовать инструкциям

BotFather попросит вас:

1. **Выбрать имя бота**
   - Например: `Bike Scraper Bot`

2. **Выбрать username**
   - Например: `bike_scraper_bot`
   - Username должен заканчиваться на `_bot`

3. **Получить токен**

   BotFather вышлет сообщение вроде:
   ```
   Use this token to access the HTTP API:
   123456789:ABCdefGHIjklmnoPQRstuvWXYZ1234567890
   ```

   Скопируйте этот токен!

---

## 2️⃣ Установить токен на Railway

### Способ 1: Через Dashboard Railway (рекомендуется)

1. Откройте Railway: https://railway.app
2. Выберите проект `bike-scraper`
3. Перейдите в `Variables`
4. Нажмите `+ Add Variable`
5. Введите:
   - **Key**: `TELEGRAM_BOT_TOKEN`
   - **Value**: `123456789:ABCdefGHIjklmnoPQRstuvWXYZ1234567890`
6. Нажмите Save

Railway автоматически перестартует приложение.

### Способ 2: Через CLI

```bash
railway variable add TELEGRAM_BOT_TOKEN "123456789:ABCdefGHIjklmnoPQRstuvWXYZ1234567890"
railway up
```

---

## 3️⃣ Проверить что бот запустился

### Способ 1: Отправить команду боту

1. Откройте Telegram
2. Найдите своего бота по username (например `@bike_scraper_bot`)
3. Нажмите Start или отправьте `/start`

Если бот ответит приветственным сообщением - успех! ✅

### Способ 2: Проверить логи Railway

1. Откройте проект на Railway
2. Перейдите в Deployments
3. Нажмите на последний deployment
4. Смотрите Logs

Ищите строку:
```
✅ Telegram бот инициализирован
✅ Сервис уведомлений запущен
```

## 4️⃣ Первое использование

### Команда для проверки

Отправьте боту:
```

```

Должен вернуться статус системы.

### Добавить поиск

```
/add_search Canyon Aeroad
```

### Проверить поиски

```
/list_searches
```

Если все работает - готово! 🎉

## 🔧 Настройка параметров

### Порог уведомления о падении цены

При добавлении поиска через API можно задать порог:

```bash
curl -X POST "https://bike-scraper-production.up.railway.app/monitoring/add-search?user_id=123456&search_term=Canyon%20Aeroad&price_drop_threshold=100"
```

- `user_id`: Ваш Telegram ID (можно узнать у `@userinfobot`)
- `search_term`: Что ищем
- `price_drop_threshold`: На сколько евро должна упасть цена чтобы отправить уведомление

## 🆘 Troubleshooting

### Бот не запускается

**Симптом:** Бот не отвечает на команды

**Решение:**

1. Проверьте что `TELEGRAM_BOT_TOKEN` установлен на Railway
2. Проверьте что токен правильный (скопировали из BotFather)
3. Перестартуйте приложение:
   ```bash
   railway up --detach
   ```

### Бот отправляет ошибки

**Симптом:** Бот отвечает `❌ Ошибка...`

**Решение:**

1. Посмотрите логи Railway
2. Проверьте что база данных подключена
3. Убедитесь что в БД есть объявления

### Уведомления не приходят

**Симптом:** Добавил поиск, но уведомлений нет

**Решение:**

1. Проверьте список поисков: `/list_searches`
2. Убедитесь что объявления по вашему поиску есть: `/deals Canyon`
3. Подождите 5 минут (сервис проверяет каждые 5 минут)
4. Смотрите логи в Railway
