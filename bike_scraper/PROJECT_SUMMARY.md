# 🚴 Bike Scraper System - Project Summary

## Проект создан! ✨

Полнофункциональная система для автоматического парсинга и анализа объявлений о велосипедах на Wallapop.

## 🗄️ База данных (8 таблиц)

```
1. listings (основные объявления)
   ├── ~50+ полей для хранения всей информации
   ├── Индексы для быстрого поиска
   └── Уникальное ограничение на source + listing_id

2. listing_history (история изменения цен)
   ├── Отслеживание всех изменений
   └── Временные серии данных

3. scraper_logs (логи парсинга)
   ├── Статистика каждого запуска
   └── Аудит всех операций

4. seller_profiles (информация о продавцах)
   ├── Рейтинг и отзывы
   └── Статистика продавца

5. bikes (нормализованные данные)
   ├── Бренд, модель, год
   ├── Компоненты (groupset, wheels, etc)
   └── Характеристики (материал, вес, etc)

6. price_analysis (анализ цен)
   ├── Статистика по брендам/моделям
   └── Тренды и аналитика

Плюс несколько вспомогательных таблиц...
```

## 🚀 REST API (12+ эндпоинтов)

```
GET  /                          # Info
GET  /health                    # Health check
GET  /bikes                     # Список велосипедов (с фильтрацией)
GET  /bike/{id}                 # Одно объявление
GET  /new                       # Новые объявления
GET  /deals                     # Выгодные предложения
GET  /search?q=...              # Полнотекстовый поиск
GET  /source/{name}             # Объявления с источника
GET  /statistics                # Общая статистика
GET  /price-analysis            # Анализ цен
GET  /sellers/{source}          # Лучшие продавцы
GET  /logs                      # Логи парсинга

Все с документацией: /docs
```

## 🎓 Технологии

### Backend
- **Python 3.11** — язык программирования
- **FastAPI** — веб-фреймворк для API
- **SQLAlchemy** — ORM для БД
- **PostgreSQL** — база данных

### Парсинг
- **curl_cffi** — HTTP клиент с имитацией браузера
- **BeautifulSoup4** — парсинг HTML
- **lxml** — быстрое парсинг HTML/XML

### Инфраструктура
- **Docker** — контейнеризация
- **Docker Compose** — оркестрация контейнеров
- **schedule** — планирование задач
- **APScheduler** — альтернативный планировщик

### Утилиты
- **python-dotenv** — управление переменными окружения
- **python-json-logger** — JSON логирование
- **Pydantic** — валидация данных

## 🔄 Workflow

```
1. init_project.py
   ├── Создает директории
   ├── Инициализирует БД
   └── Проверяет зависимости

2. scheduler.py (в фоне)
   └── Каждые 10 минут:
       ├── Парсит новые объявления
       ├── Дедуплицирует
       ├── Парсит информацию
       ├── Скачивает изображения
       ├── Сохраняет в БД
       └── Логирует результаты

3. api_main.py (в фоне)
   └── Слушает на :8000
       ├── Обслуживает API запросы
       ├── Возвращает JSON
       └── Предоставляет документацию
```
